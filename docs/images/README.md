# Guide Screenshots

This folder is reserved for screenshots used by `HOW_TO_USE.md`.

Last reviewed: Sunday, August 9, 2026.

Recommended screenshot style:

- Use small, cropped images focused on the relevant button, table, or dialog.
- Avoid showing sensitive database credentials, passwords, customer data, or supplier account details.
- Use consistent browser/image scaling if screenshots are captured from the same display.
- Name files to match the placeholders already used in the guide.
