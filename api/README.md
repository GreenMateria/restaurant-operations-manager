# StoreOps Manager API

The current architecture, route inventory, build/local-run/deployment instructions, authentication, database schema, and infrastructure/recovery procedures are in the single [Project Reference](../PROJECT_REFERENCE.md#29-api-reference).

The API is a standalone Maven project. Its executable routes are defined in `src/main/java/ca/foodinventory/api/ApiRoutes.java`, and its deployment definition is [template.yaml](template.yaml).

Historical API proof notes are [archived](../docs/archive/2026-10-08/API_README.before-consolidation.md); they are not current deployment instructions.
